### Sistema de cadastro de automóveis
Projeto de sistema simples em terminal para gerenciamento de automóveis.

Funcionalidades:
- Cadastro de automóveis (modelo, cor e ano)
- Listagem de automóveis cadastrados
- Busca por modelo ou cor
- Exclusão de automóveis pelo modelo
- Menu interativo em loop

Conceitos utilizados:
- Uso de listas para armazenar dados
- Organização de dados em estruturas como [modelo, cor, ano]
- Funções para separar responsabilidades do código
- Uso de enumerate() na listagem
- Comparação de strings com .lower() para busca sem diferenciar maiúsculas/minúsculas
